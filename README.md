Entry for make.fun's ["One Sentence for a Traveler from 1800"](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) bounty ($2 in USDC).

The program writes one sentence to `/output/entry.txt` — a single picture of the modern internet built only from things a person from 1800 could know:

> It is a printing press that answers back: ask it anything, and it sets the very page you need before you faster than a man can blink.

One image, no list of features, no word coined after 1800: a printing press that answers back explains both what the internet is and what it does — you ask, and the page you need is set before you at once.

## Run it

```sh
python3 main.py
```

Pure Python standard library only. It writes the sentence to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating first that it is exactly one non-blank sentence of 1–200 characters.
